# G12: Accuracy vs privacy budget for differentially private SQL aggregates

Course assignment (DBMS, G12: privacy-preserving databases and DPDP Act 2023).
Measures how the error of differentially private COUNT, SUM, AVG and GROUP BY
queries changes with the privacy budget epsilon, clamping bounds and dataset size.

## Requirements
Python 3.10+ and: `pip install pandas numpy matplotlib opendp`

## Run
```bash
python g12_dp_experiment.py        # data.csv, results.csv, summary.csv, timing.csv, fig1-3
python g12_extra_experiments.py    # clamp_results.csv, size_results.csv, fig4-5
```
Both scripts use fixed random seeds, so results are reproducible.
Total runtime is about one minute.

## Data
Synthetic (100,000 rows: age, salary, city, department), generated by
`g12_dp_experiment.py` with seed 42. No real personal data is used.

## Method
Laplace mechanism with noise scale sensitivity/epsilon. COUNT has sensitivity 1;
SUM uses the clamping upper bound; AVG = noisy SUM / noisy COUNT with the budget
split equally; GROUP BY uses parallel composition (disjoint groups).
1,000 trials per query per epsilon in {0.01, 0.1, 0.5, 1, 2, 5, 10}.

## Files
| File | Content |
|---|---|
| g12_dp_experiment.py | Main experiment (RQ3) |
| g12_extra_experiments.py | Clamping and dataset-size experiments |
| results.csv, summary.csv | Per-trial and aggregated errors |
| group_results.csv | GROUP BY errors per city |
| timing.csv | Runtime, plain vs DP |
| fig1-fig5 | Figures used in the article |

## Limitations
Hand-written numpy Laplace mechanism (no privacy accounting library), single
machine, synthetic data, timings measured in pandas rather than a SQL engine.
